# Dorina Authority System Theme Mockups

Private mockup board for selecting the visual direction of the big Mental Health Authority platform before changing the production `/authority-system/` pages.

## Variants

- **A · Warm Authority** — closest to Dorina Women Circle; dark, gold, intimate, premium.
- **B · Clinical Executive** — teal/charcoal, more serious and boardroom-like.
- **C · Editorial Calm** — light, readable, consultant-report feel for long documents.
- **D · Command Center** — high-contrast internal dashboard/control-room style.

## Guardrail

This is a mockup only. Public landing and Women Circle pages should remain unchanged until AK selects a direction.
