# Claude Design Upload Prompt — Dorina Authority Website You are Claude Design refining a complete static GitHub Pages website for Dorina Salman’s mental health management / workplace wellbeing authority package. ## Surface choice This is primarily a **Decide / Learn** surface: the reader must understand a serious strategy package, read documents in the right order, and know exactly what to do next. The design should feel premium, warm, calm, trustworthy, and executive — not like a generic SaaS landing page. ## Files I am uploading Upload these files/folders together: - `index.html` - `step-by-step-guide.html` - `claude-design-upload-prompt.html` - all document HTML pages in the root folder - `assets/style.css` - the `markdown/` folder as the source-of-truth text copy ## Project context Dorina is being positioned as a non-clinical workplace wellbeing educator and mental health literacy advocate in Lebanon. The package includes LinkedIn authority building, a 12-month calendar, workshop system, exercises/handouts, marketing funnel, approval workflow, Instagram expansion, Lebanon opportunity map, premium prompt library, and external strategic review. ## Hard constraints 1. Do **not** position Dorina as a therapist, psychologist, counselor, clinician, doctor, treatment provider, or crisis-support provider. 2. Preserve the non-clinical education boundary: workplace wellbeing, mental health literacy, stress literacy, burnout prevention, boundaries, routines, emotional organization, and help-seeking. 3. Do not invent credentials, testimonials, metrics, partnerships, crisis numbers, awards, or clinical claims. 4. Do not mix in the older Dorina package. This website must stay the single consolidated latest package. 5. Keep the website phone-readable and GitHub Pages compatible: static HTML/CSS/JS only, no backend, no build step required. 6. Keep document content accurate; improve presentation, hierarchy, navigation, and usability, not the strategic substance unless you clearly mark suggestions. 7. Add visual polish without AI-design slop: no generic purple gradients, no fake dashboard stats, no filler icons, no glassmorphism for its own sake. ## Design direction - Premium, calm, high-trust, editorial/documentation quality. - Warm cream / deep teal / restrained gold can be retained or improved. - Strong reading experience with clear document order and section hierarchy. - Better mobile navigation and document readability. - Include a clear “Start here” path and persistent access to the guide. - Make the prompt library and approval workflow easy to find. ## Output requested Return a refined static website package with: 1. Updated `index.html` 2. Updated `step-by-step-guide.html` if needed 3. Updated `claude-design-upload-prompt.html` if needed 4. Updated `assets/style.css` 5. No duplicate document pages unless there is a clear reason 6. A short change log explaining what changed 7. A quick self-audit against the slop diagnostic ## Quality bar The final page should feel like a polished executive review portal for a sensitive wellbeing strategy, not a template. Prioritize trust, clarity, navigation, and readability over decoration.
